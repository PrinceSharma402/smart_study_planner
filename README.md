# 📚 Smart Study Planner

Smart Study Planner is a simple and user-friendly web application designed to help students organize their study tasks, track progress, and manage deadlines effectively. The project focuses on improving productivity through a clean interface and a chronological study timeline.

---

## 🚀 Project Overview

Managing multiple subjects and deadlines can be challenging for students. Smart Study Planner provides a structured way to plan study tasks, set due dates, and monitor completion status. All data is stored locally in the browser, making the application fast and easy to use without any backend setup.

---

## ✨ Features

- ➕ Add study tasks with subject name and due date  
- 📅 Automatic chronological timeline based on due dates  
- ✅ Mark tasks as completed  
- ❌ Delete tasks easily  
- 💾 Persistent storage using Browser Local Storage  
- 📱 Responsive and clean UI for desktop and mobile  

---

## 🛠️ Tech Stack

- **HTML5** – Structure of the application  
- **CSS3** – Styling and responsive design  
- **JavaScript (Vanilla JS)** – Core logic and DOM manipulation  
- **Local Storage** – Data persistence  

---

## ⚙️ How It Works

1. Enter a study task or subject name.  
2. Select a due date and time.  
3. Click **Add Study Task** to add it to the timeline.  
4. Tasks are automatically sorted by due date.  
5. Mark tasks as completed or delete them when finished.  
6. All tasks remain saved even after refreshing the page.
